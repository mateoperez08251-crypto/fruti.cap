# fruti-prompt-review

Aplicar a cualquier escena; los ejemplos del arco de la heladería no son reglas universales.
El preset `frutinovelas` es el habitual del proyecto; usar `general` si se solicitan
otros sujetos o estilos. Respetar las decisiones expresas de la escena actual.

1. Leer [núcleo de dirección](../../../frutinovelas-studio/docs/DIRECTOR_CORE.md).
2. Leer y seguir [procedimiento de esta skill](../../../frutinovelas-studio/docs/skills/fruti-prompt-review.md).
3. Para preset `frutinovelas`, consultar [preferencias](../../../frutinovelas-studio/docs/FRUTINOVELAS_PREFERENCES.md).
4. Cargar continuidad de un capítulo solo si corresponde a la historia solicitada.

Por MCP, `get_directing_guidance` devuelve estas guías al cliente conectado.
